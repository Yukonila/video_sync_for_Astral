# Video Sync

一个 Chrome 扩展，让两台（或更多）Windows 电脑远程同步视频播放。在一台电脑上播放、暂停、拖动进度条，另一台会自动跟随。

适用于：和朋友异地一起看电影、和家人同步追剧、跨设备同步播放进度。

---

## 工作原理

- 两台电脑安装同一个 Chrome 扩展
- 其中一台电脑同时运行一个轻量的 Node.js 服务器
- 两台电脑通过 **Astral** 组建虚拟局域网，让异地的机器像在同一个局域网里
- 扩展连接到这个服务器，输入相同的**房间号**即可进入同一房间
- 房间内任何一方的播放 / 暂停 / 进度操作，都会实时广播给房间内其他人

服务器只转发「播放 / 暂停 / 进度」这类指令，**不传输任何视频内容，也不记录你在看什么**。

---

## 前置要求

- 两台 Windows 电脑
- 每台安装 Chrome 116 或更高版本
- 每台安装 [Astral](https://astral.sh/)（或类似的虚拟组网工具），并加入同一个虚拟网络
- **其中一台**安装 [Node.js](https://nodejs.org) 16 或更高版本（LTS 版即可）

## 一、部署服务器

选**其中一台电脑**当服务器，下面所有操作都在这台上进行。

### 1. 安装 Node.js

去 [nodejs.org](https://nodejs.org) 下载 LTS 版，一路下一步安装。装完后打开 PowerShell，输入：

```powershell
node -v
npm -v
```

能显示版本号就说明装好了。

### 2. 放好项目文件

把项目解压到一个固定位置，例如：

```
D:\video_sync\
├── extension\
├── server\
├── start-server.bat
└── README.md
```

### 3. 启动服务器

**方式一：双击启动（推荐）**

直接双击项目根目录的 `start-server.bat`。

首次运行会自动安装依赖（`npm install`），之后直接启动。会弹出一个黑色命令行窗口，看到类似下面的输出即为成功：

```
========================================
Video Sync server listening on port 3000
----------------------------------------
本机可用 IPv4 地址：
  [astral] 10.126.126.1
  [以太网] 192.168.110.208
  ...
----------------------------------------
扩展里填写服务器地址时，格式如下（注意不要带尖括号）：
  另一台机器：ws://<Astral虚拟IP>:3000/ws
  本机自己：  ws://127.0.0.1:3000/ws

举例：如果 Astral 虚拟 IP 是 10.126.126.1，就填
  ws://10.126.126.1:3000/ws
========================================
```

**记下 `[astral]` 那一行的 IP**，这就是另一台机器要填的地址。

**方式二：命令行启动**

```powershell
cd D:\video_sync\server
npm install
node index.js
```

> 这个黑色窗口**不能关**。关了服务器就停了。如果希望它开机自动在后台运行，看下面的「开机自启」章节。

### 4. 放行防火墙

Windows 防火墙默认会拦截 3000 端口的入站连接。在服务器这台机器上：

1. 打开 **Windows Defender 防火墙** → **高级设置**
2. 左侧点 **入站规则** → 右侧 **新建规则**
3. 类型选 **端口** → 下一步
4. **TCP**，特定本地端口填 `3000` → 下一步
5. **允许连接** → 下一步
6. 全部勾选 → 下一步
7. 名称填 `Video Sync` → 完成

### 5. 开机自启（可选）

如果不想每次手动双击 `start-server.bat`，可以用 Windows 的任务计划程序让它在开机时后台静默运行。

1. 按 `Win + R`，输入 `taskschd.msc`，回车
2. 右侧点 **创建任务**
3. **常规**标签：
   - 名称：`Video Sync Server`
   - 勾选 **不管用户是否登录都要运行**
   - 勾选 **使用最高权限运行**
4. **触发器**标签 → 新建：
   - 开始任务：**启动时**
5. **操作**标签 → 新建：
   - 操作：**启动程序**
   - 程序或脚本：`D:\video_sync\start-server.bat`
   - 起始于：`D:\video_sync`
6. **设置**标签：
   - 勾选 **如果任务失败，按以下频率重新启动**，间隔 1 分钟
   - 取消勾选 **如果任务运行时间超过以下时间，停止任务**
7. 确定保存

重启一次，打开 PowerShell 输入：

```powershell
netstat -an | findstr 3000
```

看到 `LISTENING` 就说明服务器在后台跑起来了。

## 二、安装 Chrome 扩展

**两台电脑都要做这一步。**

1. 下载本仓库的 ZIP 并解压，或 `git clone` 到本地
2. 打开 Chrome，地址栏输入 `chrome://extensions`
3. 打开右上角的 **开发者模式**
4. 点击 **加载已解压的扩展程序**
5. 选择解压出来的 `extension` 文件夹
6. 扩展图标会出现在浏览器工具栏

---

## 三、配置扩展

### 服务器那台电脑

- 点击扩展图标
- **服务器地址**：`ws://127.0.0.1:3000/ws`
- **房间号**：点「生成随机房间号」，或自己填一个，比如 `123456`
- 点「连接」，状态显示「已连接」

### 另一台电脑

- 点击扩展图标
- **服务器地址**：`ws://10.126.126.1:3000/ws`
  - 把 `10.126.126.1` 换成你服务器启动时 `[astral]` 那一行的 IP
  - **不要带尖括号 `< >`**
- **房间号**：和服务器那台填**完全一样**的
- 点「连接」

### 验证连接

服务器那台的终端应该显示：

```
[+] room=123456 当前连接数=2
```

连接数为 2 就说明两台都进同一个房间了。

---

## 四、同步播放

1. 两台电脑**手动打开同一个视频链接**（例如同一个 YouTube 视频）
2. 在任意一台点播放，另一台会自动跟随
3. 暂停、拖动进度条同样会同步

> **注意**：扩展只同步播放状态，不会自动帮对方打开视频页面。两台电脑需要先打开同一个视频链接，再通过房间号同步。

## 五、用户设置说明

点击扩展图标后，弹窗里可以配置以下内容。

### 服务器地址（必填）

- 格式：`ws://IP:3000/ws`
- 服务器那台填 `ws://127.0.0.1:3000/ws`
- 另一台填 `ws://<Astral虚拟IP>:3000/ws`

### 房间号（必填）

- 房间号是进入同一房间的凭证，**知道房间号的人都能加入**
- 两台电脑必须填**完全一样**的房间号
- 建议使用「生成随机房间号」按钮，避免与他人撞车

### 连接状态

- **已连接（房间 xxx）**：连接正常
- **未连接 / 连接失败**：检查服务器是否运行、地址是否正确、防火墙是否放行

## 常见问题

**Q：另一台电脑显示「连接失败」怎么办？**

按顺序检查：
1. 服务器那台的 `node index.js` 是否还在运行（黑窗口是否还开着）
2. 服务器地址是否填对，**不要带尖括号**，格式是 `ws://IP:3000/ws`
3. 在另一台电脑的 PowerShell 里测试端口：
   ```powershell
   Test-NetConnection 10.126.126.1 -Port 3000
   ```
   看到 `TcpTestSucceeded : True` 就说明网络通了
4. 如果端口不通，检查服务器那台的 Windows 防火墙是否放行了 3000 端口

**Q：服务器日志一直显示 `+1 / -1` 循环怎么办？**

这是 Chrome 的 Service Worker 被浏览器回收导致的。扩展代码里已经加入了保活和指数退避重连，正常情况下不会出现。如果仍然出现，重新加载扩展，或重启 Chrome。

**Q：为什么两台电脑延迟有点大？**

在 Astral 虚拟网络下，延迟通常在 20–50ms 之间，同步体验接近「同时」。如果感觉延迟明显，检查：
- Astral 是否正常工作（`ping` 对方的虚拟 IP）
- 是否有多余的扩展实例或标签页在反复重连

**Q：为什么对方打开了视频但我这边没自动打开？**

扩展不传输视频 URL，只同步播放状态。两台电脑需要手动打开同一个视频链接。

**Q：暂停 / 播放有时候不同步？**

确保两台电脑打开的是**同一个视频**，并且扩展显示「已连接」。部分网站的播放器会拦截扩展的控制，导致同步失败。

**Q：房间号会泄露我在看什么吗？**

不会。服务器只转发播放 / 暂停 / 进度指令，无法知道视频内容或标题。

**Q：可以支持三台或更多电脑吗？**

可以。服务器按房间广播，同一个房间号下可以有多台电脑。房间号相同即可。

**Q：`.bat` 文件双击后窗口一闪而过怎么办？**

说明启动失败了。在 `server` 目录里手动打开 PowerShell，运行 `node index.js`，看具体报错。常见原因是 Node.js 没装好，或依赖没安装成功。

## 技术栈

- **Chrome 扩展**：Manifest V3，Service Worker + Content Script
- **服务器**：Node.js + `ws`
- **通信**：WebSocket（局域网 / Astral 虚拟网络内使用 `ws://`）
